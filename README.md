# Крестики-нолики // Cyberpunk

Игра «Крестики-нолики» в неоново-киберпанк-стиле. Чистый HTML/CSS/JS, без сборщиков и зависимостей.

## Запуск

Просто открой `index.html` двойным кликом в браузере (Chrome, Firefox или Edge).

## Режимы

- **2 игрока** — по очереди на одном устройстве.
- **VS AI** — выбери, каким символом играть (X или O), ИИ ходит по алгоритму minimax с альфа-бета отсечением и никогда не проигрывает.

## Управление

- Клик по клетке — сделать ход.
- Restart — начать раунд заново (счёт сохраняется).
- Menu — вернуться в меню.
- Иконка звука (правый верхний угол) — выключить/включить звук.
